# Golden Mobil Auto — Car Rental in Batam

Single-page website for Golden Mobil Auto (goldenmobilauto.com): real fleet with published daily rates, EN/ID language toggle, booking via WhatsApp, and a Where to Go in Batam guide.

Open `index.html` in a browser — no build step. `src/main.ts` is a typed TypeScript port of the page logic (check: `npx -p typescript tsc --noEmit`); `index.html` remains the runnable page.

Fleet data and images: goldenmobilauto.com. Office: Komplek Limindo Trade Centre Blok A No. 12A, Taman Baloi, Batam.
